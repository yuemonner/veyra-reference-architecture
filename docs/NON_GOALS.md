# Non-Goals

Veyra Reference Architecture v0.1 does not attempt to:

- operate robots
- replace ROS, MCAP, Foxglove, Formant, Datadog or OT monitoring tools
- infer root cause as fact
- build a universal ontology for every physical system
- stream high-volume sensor data
- provide production auth, tenancy or compliance certification
- provide financial underwriting decisions
- guarantee downtime reduction
- automate deployment, rollback or dispatch

The focus is narrow:

> Reconstruct evidence for one high-consequence operational decision.
